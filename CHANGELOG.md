# Changelog

All notable changes to WhenFound are recorded here.

## [0.1.0] - 2026-09-15

### Added

- Deterministic parsing of ISO and written dates, relative days, weekdays, times, ranges, locations, descriptions, and timezones.
- Review-only preview command.
- Explicit `.ics` export with overwrite protection.
- iCalendar text escaping, UTF-8 line folding, confidence, and warning fields.
- Test suite, CI matrix, security policy, and verification record.
